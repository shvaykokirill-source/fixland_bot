# ⚔️ Telegram-бот проекта FixLand (Minecraft)

Многофункциональный Telegram-бот для Minecraft-проекта **FixLand** на **Python (aiogram 3.x)**, с асинхронной базой данных **SQLite (aiosqlite)**, веб-сервером для хостинга (Render и аналоги) и интерактивной модерацией через группу.

---

## 🌟 Возможности бота

### 1. 🛒 Донат-магазин и услуги
- **Каталог всех 9 привилегий**: Hero, Titan, Prince, Phoenix [ХИТ], Overlord [ВЫБОР], Guardian, Kratos, Phantom, Custom [ТОП] с подробным описанием китов и команд.
- **Покупка донат-рублей (Ⓟ)** по курсу `1 ₽ = 100 Ⓟ`.
- **Снятие наказаний**:
  - 🔓 **Разбан игрового аккаунта** (с вводом никнейма нарушителя).
  - 🔈 **Размут игрового аккаунта** (с вводом никнейма).
- **Способы оплаты**:
  - 🇷🇺 Банковская карта РФ / СБП
  - 🇪🇺 Карта Европы (Visa / Mastercard)
  - 🅿️ PayPal
  - 💸 FunPay
  - ⚡ CryptoBot / Криптовалюта
  - 💬 Другое (индивидуальное обсуждение с менеджером)
- Загрузка чека/скриншота оплаты покупателем и моментальная отправка карточки заказа в чат администрации с кнопками `[✅ Подтвердить]` и `[❌ Отклонить]`.
- История заказов (`📦 Мои заказы`).

### 2. 🛡️ Детальная анкета на должность Хелпера (16 пунктов)
Пошаговая анкета с возможностью отмены:
1. Никнейм на сервере
2. Возраст
3. Адекватность (1-10)
4. Грамотность (1-10)
5. Опыт работы и доказательства
6. Навыки проверки игроков на читы (1-10)
7. Программы для проверок (минимум 4 без Anydesk/TG/DS)
8. Наличие микрофона и наушников
9. Онлайн в день (от 4 часов)
10. Почему должны выбрать вас
11. Мини-рассказ (от 35 слов): «Как я вижу себя в роли администратора»
12. Знание правил проекта (1-10)
13. Объяснение терминов (Бан, Кик, Мут — от 10 слов на каждый)
14. Часовой пояс
15. Привязка Telegram
16. Устройство (PC, Ноутбук)

Карточка заявки поступает в чат администрации:
- При нажатии `[✅ Принять кандидата]` куратор закрепляется, кандидату в ЛС моментально приходит уведомление.
- При нажатии `[❌ Отклонить заявку]` кандидат получает вежливый отказ в ЛС.

### 3. 🚨 Система жалоб
Две категории с проверкой правил:
- 👤 **Жалоба на игрока** (Ник подателя, ник нарушителя, дата, причина, доказательства, дополнительно).
- 🛡️ **Жалоба на команду проекта (администратора)**.
- Памятка при подаче (отказ за обрезанные скрины, фото с телефона, оскорбления, требования к рекам от 1 мин с таймкодом).
- Интерактивные кнопки модерации в группе (`[✅ Одобрить / Наказать]` и `[❌ Отклонить]`) с оповещением игрока.

### 4. 🎬 Полноценный Медиа-Центр
- **Строгий доступ**: открыт только официальным медиа-партнёрам и администрации. Обычные игроки видят предложение подать заявку в медиа.
- **Функционал для медиа-партнёров**:
  - 💸 **Запрос выплаты за просмотры** (ссылка, статистика, реквизиты).
  - 🎁 **Запрос медиа-набора / бонусов / персонального промокода**.
  - 📜 **Тарифная сетка и критерии** (YouTube, Shorts, TikTok, Стримы).

### 5. 👥 Управление ролями персонала прямо в группе
В спец. группе (`ADMIN_CHAT_ID`) администраторы могут выдавать и снимать роли:
- `/роль медиа <ID>` или ответом на сообщение `/роль медиа`
- `/роль модер <ID>` или `/роль модератор <ID>`
- `/роль хелпер <ID>`
- `/роль админ <ID>`
- `/роль снять <ID>`
- Короткие быстрые команды: `/медиа <ID>`, `/модератор <ID>`, `/хелпер <ID>`, `/админ <ID>`, `/снять <ID>`
- Список состава: `/состав` или `/staff`
- При назначении бот автоматически оповещает пользователя в ЛС и обновляет его кнопки в меню (появляется доступ в админ-панель или медиа-центр).

### 6. ❓ Вопросы и Поддержка
- Кнопка в главном меню с частыми вопросами (FAQ) и прямым контактом поддержки: **[@Hupiiaristo](https://t.me/Hupiiaristo)**.

### 7. 👑 Исправленная Панель управления (`/admin`)
- 📊 **Полная статистика**: игроки, состав, заказы, выручка, статус заявок и жалоб.
- ⚙️ **Настройки и реквизиты**: редактирование реквизитов карт РФ, Европы, PayPal, FunPay, CryptoBot, цен на разбан/размут и ссылки на поддержку прямо из интерфейса бота!
- 👥 **Список персонала и кураторов**.
- 📢 **Массовая рассылка** всем пользователям бота с поддержкой фото и текста.

## 🛠️ Настройка и запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Настройте файл `.env`:
   ```ini
   BOT_TOKEN=ваш_токен_бота
   ADMIN_CHAT_ID=-100xxxxxxxxxx
   ADMIN_IDS=123456789
   DATABASE_PATH=shop.db
   ```
3. Запустите бота:
   ```bash
   python main.py
   ```
